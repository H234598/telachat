## 0.49.0 Provider cleanup

- Removed the duplicate default `tki` provider from generated configs.
- Kept `tki` as a compatibility alias so old sessions and folder backends still
  resolve to the HuggingFace profile when they go through config validation.

  both by default for the OpenAI Responses profile to avoid GPT-5.x sampling
  parameter incompatibilities.
- Migrated the local user config after writing
  `~/.config/telachat/config.toml.bak-0.49.0-provider-cleanup`.

## 0.50.0 Skill watchdog

- Added `telachat skill-watchdog` to compact oversized Codex Skill
  frontmatter descriptions while preserving the full Skill body.
- Tk and GTK start the watchdog once at launch and then hourly in a daemon
  thread unless `TELACHAT_DISABLE_SKILL_WATCHDOG=1` is set.
- Live run compacted the active HeyGen cache descriptions plus matching
  temporary plugin descriptions; backups were written next to each changed
  `SKILL.md`.
