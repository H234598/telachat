# Session 2026-05-26

## 0.49.0 Provider cleanup

- Removed the duplicate default `tki` provider from generated configs.
- Kept `tki` as a compatibility alias so old sessions and folder backends still
  resolve to the HuggingFace profile when they go through config validation.
- Renamed the visible HuggingFace model to `TKI` and mapped it internally to
  `Qwen/Qwen2.5-1.5B-Instruct` for API calls.
- Added per-profile `send_temperature` and `send_top_p` switches and disabled
  both by default for the OpenAI Responses profile to avoid GPT-5.x sampling
  parameter incompatibilities.
- Migrated the local user config after writing
  `~/.config/telachat/config.toml.bak-0.49.0-provider-cleanup`.

## 0.52.0 GUI options

- Added persistent Tk/GTK options for theme, app icon, chat background,
  profile-header validation, and Skill-watchdog enablement.
- Imported the provided SVG icons and generated PNG assets for desktop use.
- Added `app_icon = "random"` hourly rotation and
  `skill_watchdog_enabled = false` as the config opt-out for the default-on
  Tk/GTK Skill watchdog.

## Post-0.52.0 correction

- Temporarily restored the safe default for new configs:
  `skill_watchdog_enabled = false`.
- Moved default prompt-template escaping out of f-string expressions so Python
  3.11 can compile `telachat.defaults`.

## 0.52.1 Safety release

- Released the Post-0.52.0 correction as `0.52.1` because `v0.52.0` was tagged
  before the Linux check exposed the Python 3.11 compile failure.
