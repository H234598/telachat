## Features

- `telachat init` creates default config.
- `telachat profiles` shows configured providers with redacted keys.
- `telachat config-check` checks local profiles, models, and secret references
  without sending an API request.
- `telachat ask "..."` sends one prompt.
- `telachat ask --save "..."` saves prompt/answer to SQLite.
- `telachat chat` starts an interactive session with slash commands.
- `telachat-gtk` starts the GTK4/Adwaita GUI.
- `telachat-tk` starts the Tk/ttk GUI.
- GTK and Tk GUIs can hide the left sidebar and the system prompt panel.
- GTK and Tk GUIs support folders, sorting, search, and slash commands:
  `/new`, `/rename TITLE`, `/delete`, `/pin`, `/unpin`, `/regen`, `/folder NAME`,
  `/rename-folder NAME`, `/delete-folder`, `/move NAME`, `/unfile`, `/sort ...`, `/search ...`,
  `/provider ...`, `/model ...`, `/left`, `/system`.
- GTK and Tk GUIs can regenerate the latest assistant answer without duplicating
  the previous user message.
- GTK and Tk GUIs include Pin/Unpin and Archive/Restore controls; pinned chats
  are listed first and archived chats are hidden from normal lists.
- GTK and Tk composer shortcut: `Shift+Enter` sends the current message.
- GTK and Tk side panes are width-adjustable with wide splitter handles.
- `openai` uses Telachat's own envfile secret.
- `codex` uses the local `codex exec` CLI and is not a `/v1` HTTP backend.
- The OpenAI profile uses the OpenAI Responses API mode.
- The OpenAI profile now defaults to `gpt-5.5` with
  `reasoning_effort = "high"`; local config backup before that change:
  `/home/teladi/.config/telachat/config.toml.bak-20260525-openai-gpt55-high`.
- Saved Telachat sessions now store the selected model in addition to the
  provider profile.
- The local config backup before profile migration is `/home/teladi/.config/telachat/config.toml.bak-20260525-gui-profiles`.
- The OpenAI key was copied into Telachat's own secret file `/home/teladi/.config/telachat/openai.env` with mode `0600`; the OpenAI profile now uses `envfile:/home/teladi/.config/telachat/openai.env#OPENAI_API_KEY`.
- The backup before switching OpenAI to envfile is `/home/teladi/.config/telachat/config.toml.bak-20260525-openai-envfile`.
- The backup before switching to Telachat's own envfile is `/home/teladi/.config/telachat/config.toml.bak-20260525-own-openai-env`.
- `telachat sessions` lists saved sessions.
- `telachat sessions --query TEXT`, `--folder NAME`, and `--sort ...` filter
  saved sessions from the CLI.
- `telachat export <id>` exports a session as Markdown.
- `telachat export-folder <folder>` exports selected folders as Markdown files
  or a single bundled Markdown file.
- `telachat backup` writes a local ZIP with SQLite history,
  `config.redacted.toml`, and `manifest.json` without raw secrets.
- `telachat restore` / `telachat import-backup` safely import backup history
  into the existing SQLite database without overwriting existing sessions.
- `telachat theme` shows or persists the GUI theme; `TELACHAT_THEME` can
  temporarily override it for one launch.
- `telachat doctor` checks config and `/models`.
- `telachat doctor --chat` also sends a short live chat request.
- OpenAI-compatible streaming SSE and non-streaming chat are supported.
- Provider profiles are configurable in TOML and can use `env:NAME` for real secrets.
- The Qwen/HF Space API is now protected by the Space secret
  `TELACHAT_API_KEYS`; Telachat uses the local `Telachat_API_Teladi` value via
  `/home/teladi/.config/telachat/qwen.env`, and `Telachat_API_ReMeLi` was shown
  once in a separate terminal.
- The old placeholder key `hf-space` is rejected by the Space.
